# 安全守護者後台：Google Apps Script 部署教學

學生送出學習記錄後，資料會自動寫進一份 Google 試算表（一次提交＝一列），並產生學習回饋。
不需要開電腦、網址固定不變。

---

## 一、建立試算表與程式（約 5 分鐘）

1. 用**學校 Google 帳號**打開 Google 雲端硬碟，新增一份試算表，命名為「**安全守護者學習記錄**」。
2. 試算表上方選單：**擴充功能 → Apps Script**。
3. 把編輯器裡原本的程式全部刪掉，貼上本資料夾 `Code.gs` 的**全部內容**，按 💾 儲存。
4. 專案名稱（左上角「未命名的專案」）改成「安全守護者後台」。

## 二、設定金鑰與活動名稱

1. 左側選單點 **⚙️ 專案設定**，捲到最下面「**指令碼屬性**」→「**新增指令碼屬性**」。
2. 新增以下屬性：

| 屬性 | 值 | 說明 |
|---|---|---|
| `GROQ_API_KEY` | 您的 Groq 金鑰（`gsk_` 開頭） | 選填。沒填就使用固定回饋 |
| `GROQ_MODEL` | 例如 `openai/gpt-oss-120b` | 選填。沒填就用 `openai/gpt-oss-120b` |
| `ACTIVITY_NAME` | 例如 `115-1安全守護者` | 選填。會寫進試算表的「活動名稱」欄 |

3. 按「**儲存指令碼屬性**」。

> 金鑰只放在這裡，**不要**寫進程式碼，也不要貼到對話或 GitHub。

## 三、部署成網頁應用程式

1. 右上角 **部署 → 新增部署作業**。
2. 左邊「選取類型」齒輪 → **網頁應用程式**。
3. 設定：
   - 說明：`第一版`
   - 執行身分：**我**
   - 誰可以存取：**任何人**
4. 按「**部署**」→ 出現授權視窗時：選自己的帳號 →「進階」→「前往 安全守護者後台（不安全）」→「允許」。
   （這是 Google 對自己寫的程式的標準提醒，程式只會存取這份試算表和 Groq。）
5. 複製「**網頁應用程式網址**」（以 `https://script.google.com/macros/s/` 開頭、`/exec` 結尾）。

**檢查：** 用瀏覽器打開這個網址，看到 `{"ok":true,"message":"安全守護者後台運作中"}` 就成功了。

> **如果「誰可以存取」沒有「任何人」這個選項**：代表學校帳號的管理員限制了對外分享，學生會連不上。
> 請改用個人 Gmail 帳號，從第一步重做一次。

## 四、接上網站

把網頁應用程式網址交給維護網站的人，設定成網站預設後台。
設定前也可以先用這種連結測試：

```
https://leilei1221.github.io/safety-activity/?api=貼上網頁應用程式網址
```

網頁應用程式網址**不是金鑰**，可以公開。

## 五、試算表欄位

| 欄位 | 內容 |
|---|---|
| 提交時間、活動名稱、班級、座號、姓名、事故 | 基本資料 |
| 骨牌1～骨牌5 | 學生寫的骨牌分析 |
| 三段五級得分、三段五級明細 | 例如 `4/5`，明細逐題列出 |
| 現場模擬得分、現場模擬明細 | 例如 `3/4` |
| 事故故事觀看 | 例如「已看完，觀看 2 分 15 秒」 |
| 學習回饋、回饋來源 | 回饋來源為「AI（Groq）」或「固定回饋」 |
| 提交編號 | 系統產生的唯一編號 |

同一位學生分析不同事故，會各自一列，**不會互相覆蓋**。

## 六、用 Autocrat 產生每人一份文件

1. 先做一份 **Google 文件範本**，在要填資料的地方寫欄位名稱並用 `<<` `>>` 包起來，例如：
   ```
   健康與護理 活動學習紀錄
   <<班級>>班 第<<座號>>號 <<姓名>>　事故：<<事故>>　提交時間：<<提交時間>>

   一、骨牌理論分析
   1. 環境因素：<<骨牌1 環境因素>>
   ...
   二、三段五級（<<三段五級得分>>）
   <<三段五級明細>>
   三、學習回饋
   <<學習回饋>>
   ```
2. 試算表選單：**擴充功能 → 外掛程式 → 取得外掛程式**，搜尋並安裝 **Autocrat**。
3. **擴充功能 → Autocrat → Launch → New Job**，依序：選範本 → 對應欄位 → 檔名建議
   `<<班級>>_<<座號>><<姓名>>_<<事故>>` → 選存放資料夾。
4. 執行方式：手動按 **Run**，或在 Autocrat 設定**定時執行**（例如每小時一次）。
   注意：學生資料是由程式寫入，不是 Google 表單送出，所以 Autocrat 的「表單送出時執行」**不會觸發**，請用手動或定時。

## 七、AI 回饋沒有出現（回饋來源一直是「固定回饋」）

在 Apps Script 編輯器上方的函式選單選 **`testGroq`** → ▶ 執行，看下方「執行記錄」：

| 執行記錄 | 處理方式 |
|---|---|
| 有沒有讀到金鑰：沒有 | 指令碼屬性名稱要完全是 `GROQ_API_KEY` |
| `HTTP 401` | 金鑰錯誤，重新貼上（前後不要有空格） |
| `HTTP 404`、model_not_found | 模型已停用：執行 **`listGroqModels`** 查可用模型，把新名稱填進 `GROQ_MODEL` |
| `HTTP 429` | 使用次數達上限，稍後再試 |

改指令碼屬性會立即生效，不用重新部署。

## 八、之後修改程式

改完 `Code.gs` 後，要到 **部署 → 管理部署作業 → ✏️ 編輯 → 版本：新版本 → 部署**，
網址不變，學生才會用到新版程式。
